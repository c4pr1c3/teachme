# 常见专题教练检查卡

这些卡片用于生成有质量的提示和审查问题，不是看到关键词就公布的答案标签。诊断阶段优先从题意、约束和暴力瓶颈出发；学生到达 L3 或完成独立建模后，再明确算法名称。

高级专题同样使用“状态/不变量 → 适用条件 → 复杂度 → 边界 → 验证”的通用协议。首版不为每个高级算法单独建立模板。

## 1. 模拟、枚举与复杂度估算

- **先问**：所有候选状态是什么？能否用直接但正确的枚举建立基线？
- **约束检查**：循环乘积、测试组数、每组规模总和、值域和输出总量。
- **正确性检查**：枚举是否不重不漏，模拟是否严格按过程更新。
- **常见陷阱**：把单次复杂度当成总复杂度；无必要优化简单题；中间值溢出。
- **迁移点**：优化通常来自减少状态、复用计算或改变枚举顺序，而非随机加常数技巧。

## 2. 排序、二分、双指针与前缀处理

- **先问**：排序后什么性质变得可用？答案或判定是否具有单调性？区间信息能否增量维护？
- **正确性检查**：二分的单调谓词、双指针不丢解的理由、前缀和差分的下标映射。
- **边界检查**：区间开闭、终止条件、空区间、`l=1, r=n` 的初值和答案不存在的情况。
- **性能检查**：每个指针是否最多移动有限次；循环内是否又排序或扫描。
- **常见陷阱**：只背 `upper_bound/lower_bound` 形式而不解释谓词；前缀乘积/和溢出。

## 3. 贪心与构造

- **先问**：局部选择为什么不会损害后续最优性？构造过程始终维护什么条件？
- **证明工具**：交换论证、领先/滞后关系、反证、调度或不变量。
- **反例方向**：相同局部选择、不同后续代价；小值与大值混合；并列情况。
- **实现检查**：排序关键字、并列处理、构造失败时是否存在输出。
- **常见陷阱**：样例符合就当证明；把“常见贪心策略”当成普遍性质。

## 4. 基础数论

- **先问**：需要整除、同余、 gcd/lcm、素数还是快速幂中的哪种结构？
- **正确性检查**：模运算恒等式、逆元存在条件、欧拉/筛法边界。
- **边界检查**：负数取模、`0/1`、素数 `2`、乘法前转为 64 位。
- **性能检查**：单次查询与预处理的权衡，筛法内存和重复查询次数。
- **常见陷阱**：把浮点用于大整数精确计算；忽略模数不素或逆元不存在。

## 5. 基础字符串

- **先问**：需要前缀/后缀、匹配、 border、周期还是子串统计？
- **正确性检查**：下标与长度、空串、重叠匹配、字符集假设。
- **实现检查**：`char` 符号、读入空格与换行、线性扫描是否真的只执行一次。
- **算法边界**：哈希需说明碰撞风险；KMP/Z 等算法要能从前缀性质解释，而非只背数组转移。
- **常见陷阱**：无符号 `size()` 参与减法；反复字符串拼接造成隐藏平方复杂度。

## 6. 基础图论与最短路

- **先问**：图是有向/无向、带权/无权、连通/可能不连通？目标是一条路径、全部距离还是连通性？
- **建模检查**：点、边和状态分别代表什么，是否因附加状态需要分层图。
- **算法条件**：BFS 针对无权或等权最短路；Dijkstra 依赖非负权；其他算法按负权、DAG 等条件选择。
- **实现检查**：0/1 下标、重边自环、访问数组、距离初始化、多测清空和递归深度。
- **常见陷阱**：只看算法名而不验证权重条件；把“遍历过”误当成“最短距离已确定”。

## 7. 基础动态规划

- **先问**：子问题是什么？一个状态包含哪些足以无后效决策的信息？
- **固定顺序**：状态含义 → 初值 → 转移 → 遍历顺序 → 答案位置 → 复杂度。
- **正确性检查**：转移是否覆盖所有决策；不可达状态是否污染答案；滚动数组是否读到本轮/上轮正确值。
- **实现检查**：初始化、越界、负无穷、取模和多测重置。
- **常见陷阱**：先写转移再补状态含义；把记忆化搜索当成自动正确；只算状态数而漏算单状态转移成本。

## 8. STL 与基础数据结构

- **先问**：需要频繁执行的核心操作是什么？操作复杂度和数据范围是否匹配？
- **选择依据**：数组、栈/队列、堆、并查集、有序集合分别提供什么不变量和操作。
- **隐藏成本**：`vector/deque/list` 的插入删除、`map/unordered_map` 的常数、堆的重复删除、字符串和容器拷贝。
- **正确性检查**：迭代器失效、空堆/空集合、重复键、比较函数严格弱序、引用生命周期。
- **常见陷阱**：为降低常数换成数组却引入巨大内存；使用 `unordered` 容器就声称绝对 O(1)。
